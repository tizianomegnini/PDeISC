# Guion de demostración

1. Mostrar login y registro.
2. Entrar como cliente y registrar una PC.
3. Crear solicitud de reparación.
4. Entrar como administrador y mostrar la orden; crear un usuario técnico.
5. Asignar técnico usando `PATCH /api/repairs/:id` desde una herramienta HTTP (por ejemplo Thunder Client).
6. Entrar como técnico y actualizar diagnóstico, presupuesto y estado.
7. Volver como cliente y mostrar el seguimiento y el historial.
8. Explicar la diferencia entre el QR de Expo Go (desarrollo) y el APK generado con EAS (instalación independiente).

No mostrar credenciales reales ni secretos `.env` en una grabación pública.
